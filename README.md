## Project Overview

This project analyses daily air quality data from 26 Indian cities (2015–2020) under the framework of **UN Sustainable Development Goal 11 — Sustainable Cities and Communities**, specifically **Target 11.6**: reducing the environmental impact of cities.

The analysis answers eight research questions about pollution levels, trends, seasonal patterns, pollutant relationships, and city-wise comparisons using Python-based data exploration and visualization.

## Running the Project

### Step 1 — Run preprocessing (must be done first)
```powershell
cd "path\to\DEV_AAT_SDG11"
python src\dfmodif.py
```
This generates:
- `dataset/processed/city_day_cleaned.csv`
- `dataset/processed/city_annual_summary.csv`
- `outputs/statistics/data_quality_report.csv`

### Step 2 — Run statistical analysis
```powershell
python src\analysis.py
```
This generates CSV tables in `outputs/tables/` and `outputs/statistics/`.

### Step 3 — Open the Jupyter Notebook
```powershell
python -m jupyter notebook notebooks\SDG11_Air_Quality_Analysis.ipynb
```
Or open JupyterLab:
```powershell
python -m jupyter lab
```
Then navigate to the `notebooks/` folder and open `SDG11_Air_Quality_Analysis.ipynb`.

Run all cells in order (Kernel → Restart & Run All).  
All 10 charts will be generated and saved to `outputs/graphs/`.

## Important Limitations

1. **Forward fill imputation** may carry single readings across long sensor gaps. Imputed values are estimates, not actual measurements.
2. **2020 data is incomplete** — covers January–July only. The low 2020 AQI partly reflects COVID-19 lockdown effects.
3. **26 cities only** — results cannot be generalised to all of India.
4. **Single station per city** — may not represent all zones within a large city.
5. **PM10 < PM2.5 anomaly** — 2,757 records have PM10 lower than PM2.5 (physically impossible), likely caused by imputation. These were flagged but not removed.
